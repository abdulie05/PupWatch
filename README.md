# 🐾 PupWatch

PupWatch is a web application for recording and managing dog-related incidents.

The project was built to gain hands-on experience designing and deploying a cloud-based application using AWS serverless services.

## 🚀 Features

- Create and record dog incidents
- View previous incidents
- React/Vite frontend
- Serverless backend
- Persistent cloud data storage
- REST API integration
